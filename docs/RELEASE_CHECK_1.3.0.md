# 1.3.0 发布前检查

本轮未发现稳定复现的发布阻断故障；首次全量浏览器测试有两项截图等待超时，单独重跑均通过，仍需留意偶发时序问题。检查不等同于商店审核通过。

## 本轮修复与发布准备

- 修复侧栏名称跨录制串用：新录制不再沿用上一份下载名称，加载已保存用例后恢复其名称；已用浏览器回归先复现失败、再验证修复。
- manifest、package.json、package-lock.json 的项目版本同步至 1.3.0。
- 更新发行说明、审核操作步骤、隐私政策的开发者信息和截图清理说明。
- 工作台移除 GitHub 开源按钮，开源说明和源码地址放入中英文商店介绍。
- 修复继续编辑用例后下载丢失分类，以及切换目录、搜索时隐藏勾选仍参与批量操作；批量删除固定确认时的目标列表。
- 长用例名增加悬停提示，重命名空名称在弹窗内校验，侧边栏压缩留白而保持文字和缩略图尺寸。
- 同一文件夹内保存、导入、移动遇到重名时自动添加编号，手动重命名冲突在弹窗内提示；不同文件夹允许同名，既有同名记录保留原状。
- 侧边栏手动保存增加所选文件夹的重名校验，冲突时保留弹窗并提示修改名称；更换目录后清除旧提示，后台编号保留为并发保存的保护。
- 用例名称统一限制为 120 字符，粘贴先截断，输入框显示长度计数；后台拒绝超长及非文本名称。
- 截图缩略图离开可视区域附近后释放图片 URL，返回时重新加载；点击放大时重新读取原图，大图关闭时释放资源并使未完成的读取失效。
- 工作台支持用例重命名；名称更新与用例写入串行处理，保留原步骤、截图和分类，并同步当前加载用例的下载名称。
- 隐私政策与 README 入口使用当前公开仓库；1.3.0 发布内容已移除公司相关注释，测试样例使用虚构姓名及部门。

- 新增浏览器实际计算的局部 AX 上下文，独立于 DOM 保存；复制给 AI、文档预览和导出均包含两份信息。关闭截图时仍采集 AX，录制说明及隐私文案同步更新。查询限时 500ms，失败保留 DOM，释放远程对象并限制临时节点引用。

- 修复 ignored AX 节点的文档输出：明确保留 DOM 兜底，最多查询三级父节点，父级参考不冒充点击目标；旧录制不再输出无意义的 role:none。

- 修复连续输入跨 iframe 或导航文档误合并：使用浏览器提供的 frameId/documentId、页面 URL 和非空 DOM 路径判断同一输入目标，避免覆盖另一输入值。
