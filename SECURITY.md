# Security Notes

The recorder stores page-derived data locally in the Chrome profile. This can include URLs, titles, DOM context, input values, and screenshots. Do not record confidential pages unless the data handling is acceptable for the local profile.

Known release constraint:

- Password input redaction is not enabled yet and is intentionally outside the current change scope.

Report security issues privately to the project maintainer rather than opening a public issue containing captured data, screenshots, URLs, or credentials.
